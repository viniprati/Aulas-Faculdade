# Aulas Faculdade

Repositório criado para organizar os exercícios, atividades e códigos que desenvolvo durante a faculdade.

A ideia é manter um registro da minha evolução ao longo do curso, desde os primeiros exercícios de lógica até conteúdos mais avançados de desenvolvimento.

## Conteúdos

Atualmente o repositório está dividido em algumas das disciplinas que já estou estudando:

### Lógica de Programação

Exercícios voltados para os fundamentos da programação, incluindo:

* Estruturas condicionais
* Estruturas de repetição
* Funções
* Cálculos e operações
* Manipulação de dados
* Exercícios como calculadora, IMC, fatorial e caixa registradora

### Front End 1

Atividades relacionadas ao desenvolvimento web e JavaScript, incluindo:

* HTML
* JavaScript
* Arrays
* Manipulação de dados no navegador

### POO1

Exercícios envolvendo conceitos que servem de base para Programação Orientada a Objetos e manipulação de estruturas de dados.

Alguns conteúdos:

* Vetores
* Matrizes
* Funções
* Manipulação de matrizes
* Gerenciamento de produtos

### Back-End

Primeiros exercícios e atividades relacionados ao desenvolvimento back-end.

Tecnologias utilizadas atualmente:

* PHP
* HTML
* Funções e organização de páginas

## Tecnologias

Durante as atividades deste repositório, algumas das principais tecnologias utilizadas são:

* JavaScript
* HTML
* PHP
* Git
* GitHub

Outras tecnologias serão adicionadas conforme as disciplinas e o curso avançarem.

## Objetivo

Este repositório não foi criado apenas para armazenar projetos finalizados.

Também quero manter aqui exercícios simples e códigos feitos durante o aprendizado, porque a ideia é conseguir acompanhar minha evolução durante a faculdade.

Daqui a alguns semestres quero poder voltar aos primeiros códigos e comparar com o que estarei desenvolvendo naquele momento.

## Estrutura

```text
Aulas-Faculdade/
├── Back-End/
├── Front End 1/
├── Lógica de programação/
├── POO1/
└── README.md
```

Cada pasta representa uma disciplina ou área estudada e contém os respectivos exercícios e atividades.

## Sobre o repositório

O conteúdo é atualizado conforme novas aulas, atividades e exercícios são realizados.

Alguns códigos podem ser simples ou representar soluções desenvolvidas durante o processo de aprendizagem. Eles foram mantidos propositalmente para registrar essa evolução.
